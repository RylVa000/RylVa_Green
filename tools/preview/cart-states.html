Workbench Keranjang

Kontrol pengembangan. Seluruh data adalah contoh; tidak ada pesanan atau reservasi stok yang dibuat.

State khusus hanya aktif pada localhost dengan parameter preview=cart. Halaman normal tidak menampilkan kontrol ini.

    Interaksi yang diperiksa langsung

    Pilih semua/sebagian, batas jumlah, input tidak valid, simpan/hapus pending, dialog Batal/Escape, penghapusan terakhir, perubahan belum disimpan, kegagalan gambar, keyboard, dan pemulihan konflik.

    Untuk offline nyata, putuskan koneksi melalui alat pengembangan browser. Untuk konflik nyata, buka dua tab Keranjang normal dan ubah salah satunya.
