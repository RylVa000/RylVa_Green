Workbench Autentikasi Pelanggan

Kontrol pengembangan untuk data contoh. Tidak membuat akun, mengirim email, atau membuat sesi produksi.

State khusus hanya aktif pada localhost dengan preview=auth. Gunakan tab baru untuk tiap skenario. Kode contoh pertama: 123456; setiap kirim ulang menaikkan kode satu angka dan membatalkan kode sebelumnya.

Reset normal hanya terbuka setelah permintaan pemulihan contoh atau dari skenario pengembangan. Kredensial tidak disimpan. Untuk menguji koneksi nyata, gunakan mode offline alat pengembangan browser.
